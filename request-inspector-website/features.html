Product tour

Every tab tells you something different.

Request Inspector opens a single request into nine focused tabs — Overview, Request, Response, Headers, Database, Hooks, HTTP API, PHP and Timeline — so you never have to reconstruct what happened from separate tools.

01 · Request Explorer

The dashboard that catches everything.

Every REST call, AJAX action, cron run, WP-CLI invocation and front-end page render is logged automatically, the moment recording is on. Four KPI cards keep the big picture visible — total requests, slowest requests, failed requests, and external API failures — while a dense, filterable table gives you method, route, status, duration, payload size and initiating component at a glance.

  • Filter by method, status range, component, request type, or duration threshold
  • Click any row to open the full 9-tab inspector or a split view
  • Global regex search across URLs, actions and SQL patterns from the top bar

02 · Overview tab

Know the "who" before the "what".

The Overview tab opens with an initiator card — which plugin, theme or core file triggered this request, down to the class, method and line number — plus a full call backtrace. Related events (queries, hooks, notices) appear as clickable chips that jump straight into the matching tab.

03 · Response Inspector

The part most debuggers skip: the response itself.

Switch between request body and response body, inspect headers in a monospace key-value table, and read the payload in a syntax-highlighted JSON viewer with line numbers, byte counters, and formatted/raw toggles. One click to copy JSON or save it as a fixture for a test.

  • Authorization and bearer tokens shown masked, with a redaction badge
  • "Save as Fixture" turns a real response into a reusable test payload

04 · Hooks Inspector

Actions and filters, in the order WordPress actually ran them.

A segmented view separates do_action() from apply_filters(), grouped by lifecycle stage, with priority, accepted-argument count, and execution time per callback. Callbacks over 5ms are flagged amber; over 20ms, red — with an inline backtrace for each.

05 · PHP / Error Inspector

The error, the code around it, and how you got there.

Fatal errors, warnings, deprecations and notices are grouped by severity with a live count, filterable by component. Expand any one to see 5–7 lines of the surrounding PHP source with the offending line highlighted, plus a five-frame backtrace with memory delta and parameter signatures per frame.

06 · Timeline / Waterfall

The full lifecycle, drawn like a network waterfall.

A millisecond ruler with zoom controls (1x, 2x, 5x, Fit) and layer toggles for DB queries, hooks and external HTTP calls. Click any phase to see its start offset, net duration, and jump directly into the Database or Hooks tab for that slice of time.
