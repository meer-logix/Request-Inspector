Install Request Inspector.

Free, self-hosted, GPL-licensed. No account, no external service, no data leaving your server.

Request Inspector v0.10.2

.zip · GPLv2 or later · ~340 KB

Download .zip

or search "Request Inspector" in Plugins → Add New once listed on WordPress.org

Requirements

WordPress6.0 or later
PHP8.0 – 8.3
MySQL / MariaDBMySQL 8.0.x or MariaDB equivalent
DiskUp to 250 MB for captured telemetry (configurable, auto-pruned)
Browser (admin UI)Chrome, Firefox, Safari, Edge — 1280px+ viewport

Install in four steps

1

Upload the zip via Plugins → Add New → Upload Plugin.

2

Click Activate.

3

Open Request Inspector → Settings and turn recording on.

4

Trigger a request on your site and watch it appear in the Explorer.
