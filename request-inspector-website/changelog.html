Release notes

Changelog

Every release, what changed, and why.

v0.10.2 Current

Latest release

  • Fixes to duplicate-query grouping in the Database Inspector when caching plugins rewrite query hashes.
  • Hooks Inspector: corrected priority-badge sort order for negative priorities.
  • Reduced tracing overhead on REST-heavy requests by batching hook capture writes.
  • Security & Redaction: added client_secret to the default redaction list.

v0.10.0

  • Added the Timeline / Waterfall tab with zoom controls and cross-tab deep links.
  • New adaptive 10% sampling mode for high-traffic production sites.
  • Introduced the immutable audit log for Security & Redaction actions.

v0.9.0

  • PHP / Error Inspector: added 5-frame backtrace with memory delta per frame.
  • Component-level capture toggles (per-plugin) added to Recording & Retention.
  • Storage usage gauge added to the Settings screen.

v0.8.0

  • First release of the Response Inspector: request/response body viewer with JSON syntax highlighting.
  • "Save as Fixture" action added for response payloads.

v0.7.0

  • Initial public build: Request Explorer, Database Inspector, and Hooks Inspector.
  • In-memory redaction engine for Authorization headers and cookies shipped by default.
Following semantic versioning. Breaking changes to stored-data schemas will always ship as a major version bump with a migration note here.
