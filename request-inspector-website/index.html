Why developers reach for it

Query Monitor tells you something is slow. Request Inspector shows you the whole request.

Instead of piecing together a page's behavior from four different tools, Request Inspector gives you one inspector — the request, the response body, every SQL statement, every hook callback, every outbound HTTP call and every PHP notice — laid out the way Chrome DevTools lays out a network request.

Request Explorer

Every REST call, AJAX action, cron run, WP-CLI command and front-end render logged in one filterable table — method, route, status, duration, payload size, initiating plugin.

screen 1

Database Inspector

Every query with duration, affected rows, caller file:line, duplicate-query grouping and an inline EXPLAIN breakdown — no more guessing which plugin fired 40 duplicate queries.

screen 4

Hooks Inspector

See every do_action() and apply_filters() call in execution order, grouped by lifecycle, with per-callback timing and priority — flagged the moment a callback crosses 5ms or 20ms.

screen 5

PHP / Error Inspector

Fatals, warnings, deprecations and notices with the surrounding source snippet, a five-frame backtrace, and memory delta per frame — right where the error happened.

screen 6

Timeline / Waterfall

A millisecond-accurate Gantt view of muplugins_loaded through shutdown, with zoom, layer toggles, and one-click jumps into the Database or Hooks tab for any segment.

screen 7

Security & Redaction

Bearer tokens, passwords, cookies and nonces are masked in memory, before anything is written to disk — with an IP allowlist, capability gate, and immutable audit log for enterprise teams.

Database Inspector

Find the query that's actually slowing you down.

Total query time, slow-query counts and duplicate-query groups are surfaced automatically. Click any row for the full statement, an EXPLAIN analysis, and the exact caller — file, function, and line.

  • Duplicate-query grouping (×N badges) exposes redundant plugin queries instantly
  • Inline EXPLAIN: access type, rows examined, key used, table-scan warnings
  • Full caller backtrace — know which plugin or theme file to fix

Recording & retention

Safe to run on production, by design.

Sample at 100%, "slow & errors only", or an adaptive 10% — with per-component capture toggles for WooCommerce, page builders, or any plugin generating noise. FIFO pruning keeps storage under your cap automatically.

  • Retention windows of 7, 14 or 30 days with a hard storage ceiling
  • Auto-disables unless WP_DEBUG is on, or an admin explicitly enables it
  • Gated to manage_options, with an optional IP allowlist

vs. Query Monitor

The response body is the difference.

Query Monitor is a great panel for hooks and queries. It doesn't show you the actual request payload or response body. Request Inspector does — with formatted JSON, headers, and redaction on both sides of the wire.
