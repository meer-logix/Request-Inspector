Privacy Policy

Last updated September 2026.

The plugin

WordPress Request Inspector is self-hosted software. All captured telemetry — requests, SQL queries, hooks, HTTP calls and PHP errors — is stored in your own WordPress database. Nothing is transmitted to Hammad Meer, to this website, or to any third party.

Sensitive values (Authorization headers, passwords, tokens, cookies, nonces) are redacted in memory before storage, per the security model. Retention and storage caps are configurable in Settings, with automatic pruning.

This website

This marketing and documentation site (requestinspector.netlify.app) is a static site hosted on Netlify. It does not use tracking cookies or third-party advertising scripts. If you submit the contact form, the information you provide is used only to respond to your enquiry.

Standard hosting logs (IP address, user agent, request timestamp) may be retained by Netlify per their own hosting policies, independent of this plugin.

Changes

This policy may be updated as the plugin or site evolve. Material changes will be reflected here with an updated date.
