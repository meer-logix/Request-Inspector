Get in touch.

Support requests, feature ideas, security reports, or just questions — this reaches Hammad directly.

This is a static demo form. Wire it to Netlify Forms, Formspree, or your preferred backend before launch.

Other ways to reach out

  • Plugin issues & bugs: describe your WordPress and PHP version, and — if possible — export the affected request as JSON from the Response tab and attach it (secrets are redacted automatically).
  • Security reports: please report privately via this form rather than a public issue tracker; response within 72 hours.
  • Developer's other work: visit hammadmeer.netlify.app for Hammad Meer's wider portfolio.
